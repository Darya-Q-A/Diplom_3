# Diplom_3

# Тестирование веб-приложения https://stellarburgers.education-services.ru/

## Структура проекта
-----
### Локаторы в директории `locators`

***constructor_page_locators.py***
Содержит локаторы конструктора

***login_locators.py***
Содержит локаторы со страницы авторизации

***order_feed_locators.py***
Содержит локаторы со страницы Лента заказов

---

### Отдельные классы с Page Object для страниц в директории `pages`

***base_page.py***
Содержит базовые методы для использования в остальных методах

***constructor_page.py***
Содержит методы для использования их в тесте test_constructor и test_order_feed (для создания заказа)

***login_page.py***
Содержит методы для использования их в тесте test_order_feed (для авторизации пользователя)

***order_feed_page.py***
Содержит методы для использования их в тесте test_order_feed (для проверки счетчиков и наличия номера заказа)

---

### Тесты в директории `tests`

***test_constructor.py***
Проверяет:
- переход по клику на «Конструктор»;
- переход по клику на раздел «Лента заказов»;
- если кликнуть на ингредиент, появится всплывающее окно с деталями;
- всплывающее окно закрывается кликом по крестику;
- при добавлении ингредиента в заказ счётчик этого ингредиента увеличивается.

***test_order_feed.py***
Проверяет:
- при создании нового заказа счётчик «Выполнено за всё время» увеличивается;
- при создании нового заказа счётчик «Выполнено за сегодня» увеличивается;
- после оформления заказа его номер появляется в разделе «В работе».
